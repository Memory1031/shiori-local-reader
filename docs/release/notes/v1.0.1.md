# Shiori 1.0.1

小版本更新，聚焦 EPUB 样式解析与阅读位置修复。可直接覆盖安装，本地书架与阅读进度保持不变。

## 更新内容

- 阅读器：修复章节末尾插图的位置保持。此前图片延迟获得尺寸触发重排时，若占位图与前面文字同页，翻页后重排会恢复到文字位置而非停留在章末插图；现在章末锚点在翻页提交或显式恢复前一直保留。
- EPUB 样式：`@import` 按深度优先展开，导入规则先于当前样式正文，原生正文与特殊页共用展开结果；移除原始 CSS 总量硬上限，改为每文档每次展开 8 MB 字符预算，超出预算的单张样式跳过，其余样式仍可用；支持 `url()` 右括号前空白并修复关键字边界误判。
- 新增样式处理与章末位置回归测试；更新文档、截图与发布流程说明。

## 安装

Android 8.0 及以上：下载本页附件 `shiori-local-reader-v1.0.1-android.apk`，覆盖安装即可保留数据。`SHA256SUMS.txt` 提供校验值，`release-info.json` 记录构建信息。应用标识为 `dev.shiori.localreader`。

iOS 15.0 及以上：无发布链路，从源码构建，步骤见仓库 `docs/development.md`。

## 格式与数据

支持范围与 1.0.0 相同，见仓库 `docs/local-import.md`；DRM、PDF、完整固定版式、完整 CSS 和高级竖排暂不支持。书架、阅读进度与偏好仍仅保存在本地。

# Shiori 1.0.1 (English)

A patch release focused on EPUB stylesheet parsing and reading-position fixes. Safe to install over an existing copy; the local bookshelf and reading progress are preserved.

## What's changed

- Reader: fixed position retention at chapter-end illustrations. Previously, when delayed image dimensions triggered a reflow while the placeholder shared a page with preceding text, reflow after a page turn restored that text position instead of staying on the final illustration. The chapter-end anchor is now retained until a committed turn or an explicit restore.
- EPUB styles: `@import` rules are expanded depth-first with imported rules placed before the current stylesheet body, and native text and special pages share the expanded result. The hard cap on raw CSS input was replaced by an 8 MB character budget per document per expansion; a stylesheet exceeding the remaining budget is skipped while others still apply. Whitespace before the closing parenthesis of `url()` is now supported, and keyword-boundary false positives were fixed.
- Added regressions for stylesheet processing and chapter-end position; updated docs, screenshots, and release procedures.

## Install

Android 8.0 and up: download `shiori-local-reader-v1.0.1-android.apk` from this release and install it over the existing app to keep your data. `SHA256SUMS.txt` provides checksums and `release-info.json` records build details. The app ID is `dev.shiori.localreader`.

iOS 15.0 and up: there is no release pipeline; build from source as described in `docs/development.md` in the repository.

## Formats & data

The supported scope is unchanged from 1.0.0; see `docs/local-import.md` in the repository. DRM, PDF, fully fixed layouts, full CSS, and advanced vertical writing remain unsupported. The bookshelf, reading progress, and preferences are still stored locally only.
