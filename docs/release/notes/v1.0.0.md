# Shiori 1.0.0

Shiori 的首个版本：面向 Android 和 iOS 的本地 EPUB/TXT 小说阅读器。

## 功能

- 导入 TXT 和无 DRM 的流式 EPUB 2/3，支持系统文件选择、打开方式及分享接收。
- 网格 / 列表书架、封面、阅读历史与继续阅读。
- EPUB 嵌套目录及页内定位，TXT 章节识别。
- 点按或拖动翻页、连续切章与简化纸张折页动画。
- 字号、行距、段间距、五档页边距和纸张主题设置。
- 保存语义阅读位置，调整排版后恢复；重新解析书籍时尽量保留进度，近似恢复会提示。
- 通过“本章链接”阅读 EPUB 脚注及辅助文档。
- 浅色 / 深色 / 跟随系统、多种强调色，中文与 English 界面。

## 安装与使用

Android 8.0 及以上：下载本页附件 `shiori-local-reader-v1.0.0-android.apk`。`SHA256SUMS.txt` 提供校验值，`release-info.json` 记录构建信息。应用标识为 `dev.shiori.localreader`。

iOS 15.0 及以上：在 macOS / Xcode 中从源码构建，配置自己的签名账户与 App Group；步骤见仓库 `docs/development.md`。

打开应用，通过“更多 → 导入”添加书籍。应用保存一份导入副本；移除书籍会删除该副本及阅读进度，外部原文件保持原样。

## 格式与数据

普通正文采用原生分页，部分 EPUB 短扉页由受限静态 WebView 呈现。支持范围见仓库 `docs/local-import.md`；DRM、PDF、完整固定版式、完整 CSS 和高级竖排暂不支持。

书架、阅读进度与偏好保存在本地；系统备份 / 换机迁移可能包含这些数据。

项目代码采用 Apache-2.0 许可证，第三方组件保留各自许可证。
